### SIGGRAPH Asia 2026 Technical Communications · [Paper](https://doi.org/10.1145/3829339.3847840)

Technical University of Munich & Munich Center for Machine Learning

Welcome to the official repository for the paper "UltraDiff: Differentiable Ray Tracing in Ultrasound for Shape Optimization". UltraDiff formulates ultrasound image formation as a time-of-flight gated path integral and provides Monte Carlo gradients with respect to scene parameters, enabling segmentation-free shape reconstruction directly from B-mode images.
